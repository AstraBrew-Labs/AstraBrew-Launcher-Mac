## 窗口尺寸与多屏适配（ai.md 窗口规范）

- **需求**：窗口不可最大化；16:9 默认 1280×720（最小 800×600、最大 1280×720）；4:3 默认 800×600（最大 1200×800）；适配高清/多屏/副屏断开回主屏。
- **关键 API**（iced 0.14，`iced::window`）：
  - `window::Settings` 有 `size/min_size/max_size/maximized/fullscreen/resizable/position` 等；**没有 `maximizable` 字段**——用 `max_size` 作为“不可最大化”的尺寸上限。
  - `window::monitor_size(id) -> Task<Option<Size>>`：返回窗口当前所在显示器的**逻辑**分辨率（已含缩放）。
  - `window::events() -> Subscription<(Id, Event)>`：`Event::Opened{..}`/`Rescaled(f32)`/`Moved`/`Resized` 等；配合 `Subscription::filter_map`。
  - `window::latest() -> Task<Option<Id>>`；`window::resize/set_min_size/set_max_size(id, ..)`。
- **关键经验**：`Task<Option<T>>::and_then(f)` 是**特化方法**，自动解包 Option，闭包直接收 `T` 且仅 Some 时执行（None 返回空任务）——不要再手动 match。
- **实现**：
  - `main.rs`：`window::Settings` 设为默认 1280×720、min 800×600、max 1280×720、`position: Centered`、`resizable/maximized:false/fullscreen:false`。
  - `app.rs`：新增 `window_profile(monitor)` 按宽高比（≥1.5 视为宽屏含 16:10，否则 4:3）返回档位；`new()` 用 `window::latest().and_then(monitor_size)` 首开校准；`subscription()` 加 `window::events().filter_map`（Opened→首开校准并 resize 到默认尺寸，Rescaled→仅更新 min/max 约束不强制改窗口大小）；`update()` 处理 `WindowOpened/WindowRescaled/MonitorMeasured`。
- **说明/限制**：macOS 绿色按钮的“全屏 Space”无法通过 iced 公开 API 禁用，`max_size` 仅约束手动调整的最大尺寸；副屏断开回主屏依赖 macOS 系统自动迁移 + 首开 `Centered` 落主屏。
- **验证**：`cargo check` + `cargo fmt` 通过（0 error/0 warning）。

## 禁用绿色按钮 + 彻底禁止独占全屏（最终方案：原生 ObjC）

- **背景**：上一方案（`resizable:false` 创建 + 运行时 `set_resizable(true)`）只能禁用绿钮、无法封禁全屏（菜单/Ctrl+Cmd+F 仍可进全屏）。用户明确要求「不要独占全屏」，故改用原生 ObjC 彻底解决。
- **最终方案**：
  - 新增依赖（与 winit 同版本去重）：`objc2 = 0.5.2`、`objc2-foundation 0.2.2`（features: NSArray/NSEnumerator/NSThread/dispatch）、`objc2-app-kit 0.2.2`（features: NSApplication/NSWindow/NSButton/NSControl），均放在 `[target.'cfg(target_os = "macos")'.dependencies]`。
  - 新增 `src/platform.rs`：`disable_zoom_button_and_fullscreen()`，用 `objc2_foundation::run_on_main(|mtm| ...)` 保证主线程执行；遍历 `NSApplication::sharedApplication(mtm).windows()`，对每个窗口 `standardWindowButton(NSWindowZoomButton).setEnabled(false)` 禁用绿钮，并 `setCollectionBehavior(behavior - FullScreenPrimary)` 移除独占全屏。
  - `main.rs`：`resizable` 恢复 `true`（手动缩放保留）；注册 `#[cfg(target_os="macos")] mod platform;`。
  - `app.rs`：`MonitorMeasured` 首开分支移除 `set_resizable`，改为 `crate::platform::disable_zoom_button_and_fullscreen()`。
- **关键 API 备忘（objc2 0.5.2 / objc2-foundation 0.2.2 / objc2-app-kit 0.2.2）**：
  - `MainThreadMarker` 在 `objc2_foundation`；`new() -> Option`（需 NSThread feature）；`run_on_main(|mtm| ...)`（需 dispatch+NSThread feature）可保证主线程。
  - `NSWindowCollectionBehavior` 是 bitflags，`-`/`& !` 可用；`FullScreenPrimary = 1<<7`。
  - `standardWindowButton(NSWindowButton)` 返回 `Option<Retained<NSButton>>`；`setEnabled` 在 NSControl（经 Deref 继承）。
  - 各 feature 门：`NSWindow`/`NSApplication`/`NSButton`/`NSControl`（app-kit）、`NSArray`/`NSEnumerator`/`NSThread`/`dispatch`（foundation）。
- **验证**：`cargo check` + `cargo fmt` 通过（0 error/0 warning）。
